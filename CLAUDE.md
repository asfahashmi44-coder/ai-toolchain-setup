# Project Guidelines

- Stack: React / Next.js
- Code Style: Clean TypeScript
# CLAUDE.md — AI & Engineering Workflow Guide

## Environment & Build Setup
- Node.js environment using React Hook Form & Zod schemas.
- Testing Framework: Jest with React Testing Library (RTL).
- Component Architecture: Strict TypeScript + Tailwind CSS formatting.

## Code & Quality Standards
- Require explicit typing on all form state and numerical range inputs.
- Enforce accessibility standard attributes (`aria-invalid`, `aria-describedby`, focus indicators).
- Prevent unhandled async promise states on form submissions.

## Git & Commit Conventions
- Use conventional commits (`docs:`, `feat:`, `fix:`, `refactor:`).
- Branch strategy: Feature branches named `feat/<feature-name>`.
